# CS2 LAN Stats

Static stats page (Nuxt, GitHub Pages) for a LAN played on 21-22 Nov 2026 with MatchZy.

- `data/stats.json` - match data, written by `scripts/export-data.ts`
- `data/demos.json` - demo files, attached to the `demos` release
- Deployed by `.github/workflows/deploy.yml` (Settings -> Pages -> Source: GitHub Actions)

Local: `pnpm install && pnpm dev`. Map images © Valve Corporation.
